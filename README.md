# Aptus Pipeline Desk (Phase 1)
Free, no build step. All data stays in your browser, encrypted. Never put client data in this repo.
Run: upload these files to a GitHub repo, then Settings > Pages > deploy from main branch. Open the Pages link.
Test: open tests.html on the same site; all lines should say PASS.
